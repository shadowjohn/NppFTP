# NppFTP v0.30.22-3wa.4 (Windows x64 Unicode pre-release)

Maintenance fork of ashkulz/NppFTP, maintained by shadowjohn/3wa. Original author credits and GPL license are retained.

## Changes since v0.30.22-3wa.3
- Fix Profile settings becoming blank after Hostname -> Tab: clip overlapping sibling windows and explicitly keep the tab background behind its content pages. Candidate 2 was accepted by the user after testing the original reproduction.
- Include the previously committed upload controls and recursive-delete improvements, including preserving delete failures before releasing listings.

## Downloads
- `NppFTP-0.30.22-3wa.4-win64.zip`: x64 Unicode plugin and license/documentation.
- `NppFTP.dll`: standalone plugin.
- `SHA256SUMS.txt`: asset checksums.

DLL version: `0.30.22-3wa.4 Unicode`; Windows numeric version: `0.30.22.4`. Close Notepad++ and back up the existing plugin before replacing its DLL. No user profiles, passwords or test configuration are included.

## Validation and limits
Release x64 build, seven PowerShell source-contract tests and nine focused executable tests passed. Connection tests use localhost only; no real FTP profiles or external servers were used. The release retains the candidate 2 source fix, with updated version metadata.

Hostname -> Tab was visually accepted by the user. Agent-driven visual automation was blocked by a window-owner mismatch. Shift+Tab, every settings page, full profiles-list dialog, dark theme and alternate DPI have not independently passed visual testing. This release does not claim broader UI or live-server coverage. See [investigation](../profile-tab-paint-investigation.md).
