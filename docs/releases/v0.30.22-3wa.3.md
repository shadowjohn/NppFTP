# NppFTP v0.30.22-3wa.3 (Windows x64 Unicode pre-release)

This is the shadowjohn/3wa maintenance fork of [ashkulz/NppFTP](https://github.com/ashkulz/NppFTP), not an upstream release. Thanks to original author Harry and the upstream NppFTP contributors. Original author credits and the GNU GPL license remain included.

## Changes since v0.30.22-3wa.2

- Connection failures now display one visible prompt. FTP/FTPS/FTPES login reply 530 and SFTP authentication rejection use an ambiguous account/password/login-method message; transport, timeout, TLS and host-key errors retain generic connection-failure wording.
- FTP/FTPS LIST timestamps retain the existing local-time interpretation instead of applying the UTC offset twice; SFTP timestamp conversion is unchanged.
- Concurrent upload settings (1-8), upload workers and urgent cached-file saves, with queue teardown and cancellation fixes. Saved cached remote files return the browser to their parent directory.
- User-directed file and recursive directory downloads, Unicode/path checks and cancellation summaries.
- Flat-browser navigation, sortable metadata columns and 64-bit file sizes/progress, plus remote-path copy feedback.

No new features are introduced by the release-version commit. It updates the fork version, package naming and these release notes.

## Downloads

Only **Windows x64 Unicode** is built and published for this release:

- `NppFTP-0.30.22-3wa.3-win64.zip`: plugin DLL plus license/documentation, including these release notes.
- `NppFTP.dll`: the same standalone x64 plugin DLL for manual installation.
- `SHA256SUMS.txt`: SHA-256 checksums for the two assets above.

The DLL reports `0.30.22-3wa.3 Unicode`; its numeric Windows file/product version is `0.30.22.3`. There is no installer in this release. Do not infer Win32, ARM64 or Linux support from this release.

## Validation and known limits

The authentication repair was accepted by the user in Notepad++. Local Windows x64 Release builds, nine loopback FTP scenarios (including wrong password, timeout, successful login and retry), libssh-result classification, queue lifecycle regressions and notification source contracts passed. CI builds the x64 package and prepares a draft pre-release on a version tag. The draft assets, embedded version, architecture and checksums are checked against the final release commit before publication.

The agent did not independently repeat a visual Notepad++ test or run FTPS TLS/SFTP server integration for the new prompt. Their coverage uses shared-path review and libssh-result policy tests. Existing parallel-upload and cancellation combinations across real FTP/FTPS/SFTP servers still need broader QA. FTP LIST timestamps do not carry a server timezone, so servers in another timezone may require future profile-level support. See [authentication validation](../authentication-failure-validation.md) for details.
